AI日报工作流构建

AI 日报工作流构建

｜ 版本：v1.1（2026-09-28）｜ 维护方式：由 Qoder 工作流逐期生成

一、用途

本工作流把一份”AI 行业快照日报”变成可重复执行的流水线：每期产出一个自包含的 HTML 日报文件（如 AI日报_2026-09-27.html），聚焦四个方向：

方向 关注什么 对应用途
AI Coding（智能体编程） 旗舰模型发布、IDE/Agent 工具、定价、安全、生产化、国产编码生态 判断编码工具链与模型选型的行动信号
具身智能（Embodied AI） 人形机器人、量产与交付、大脑/VLA、触觉、资本与标准 跟踪从”炫技”到”交付”的产业拐点
国产大模型 DeepSeek / 智谱 / 月之暗面 / 阿里等换代、开源、定价、出海 国产开源在 Agent 与成本维度的全球位置
金融 × AI 银行规模化落地、智能问数（ChatBI）、监管制度（金发〔2026〕8 号） 结合银行业务背景的合规与落地双视角

设计出发点：以 AI日报_2026-08-18.html 快照为版式与口径基准，风格、结构、卡片写法保持一致，只更新数据与信息；新增板块（国产大模型专区、金融 × AI 专区）经确认后固化为标准结构。

适用与不适用：适用于每日/按需快速通读行业要点并留存档案；不适用于投资决策依据——所有评分与价格以原站实时口径为准。

二、交付物与命名

命名规则：AI日报_YYYY-MM-DD.html，日期 = 数据截止日。单文件交付，CSS 内联，无外部依赖，浏览器直接打开即可。

三、工作流构成（每期六步）

步骤 1 · 基准采集（榜单类）

数据源 提供 抓取方式 已知问题
llm-stats.com 综合分、Coding/Agent 分项、上下文、速度、综合价 $/M WebFetch 仅实时口径，无法回溯历史；概览页有时缺 Reasoning/参数列
livebench.ai 无污染客观分（23 任务 / 7 类）+ $/任务 浏览器渲染（页面为 JS 应用，WebFetch 抓不到） 六个月才刷新一次 release
artificialanalysis.ai Intelligence Index、速度、价格交叉验证 WebFetch 概览页部分价格分档不列具体值

规则：抓取当日必须记录”抓取日期 + release 版本”；抓不到的数据宁可标注缺失，不得沿用旧数据冒充新数据。

步骤 2 · 新闻检索（四类多轮）

按四个方向各做 24 轮 WebSearch（中文优先，辅以官方公告），再用 WebFetch 精读 36 篇关键文章。筛选标准：对从业者有”行动含义”（选型、成本、合规、时点），每条必须落到具体日期（卡片右上角”时效”标签）。

步骤 3 · 专区判断（规则化，不硬编）

  • 国产大模型专区：DeepSeek 有实质进展 → 标”今日有 D ✅”，无则如实写”今日无 D”；同步收录智谱/Kimi/阿里当期换代、开源、定价、出海事件。
  • 金融 × AI 专区：收录银行落地数据、监管文件、智能问数动态；只允许使用不晚于本期数据截止日的信源。

步骤 4 · 计算层

  • 性价比 = LLM Stats Score ÷ 综合价（$/M），按性价比降序画条形图（宽度 = 数值/最大值）。
  • 表 D 选”当期最值得拆解的价格事件”（如 08 期 = DeepSeek 峰谷明细；09 期 = 九月三旗舰价格地震），无重大价格事件可省略并注明。

步骤 5 · 组装 HTML

固定七段结构（顺序与样式不得随意变更）：

CSS 以上一期为基准原样复用，新增板块样式参照 cnzone / finzone 命名法扩展。

步骤 6 · 验证（交付前必做）

  1. 数字可追溯：每张表、每个价格能对应到步骤 1 的抓取结果。
  2. 结构断言：浏览器打开，evaluate_script 统计 .card = 15、table.tbl = 5、七个 h2 齐全。
  3. 渲染抽查：页眉 + 两个新专区截图确认无版式破损。
  4. 口径诚实：真实抓取 / 快照沿用 / 标题级信息（原文反爬未核验）三类在文中显式注明。

四、快速使用

  • 正常刊：对话中说”跑今天的 AI 日报”即可，全流程约需多轮检索。
  • 补刊（历史日期）：如”生成 8 月 27 日的日报”。新闻严格限定在截止日之前；榜单无法回溯时沿用最近一次快照并在表头与页脚注明口径（见 08-27 期做法）。
  • 可选升级（尚未启用）：Qoder 定时任务每日自动触发；或做成打开即拉取榜单的交互式页面。

五、后续需重点关注领域

  1. Agentic Coding 口径之争：LiveBench 已把 Agentic Coding 设为独立分项，DeepSeek V4.1 Flash（77.3）首次反超闭源旗舰；跟踪各榜单是否跟进该维度、以及 SWE/Terminal-Bench 类基准的换代。
  2. 单任务成本”分厘级”竞赛：V4.1 Flash $0.029/任务、GLM-5.3 Flash $0.031；关注峰谷定价扩散、缓存计价成为主战场，以及”按子智能体分档控模”是否成为默认工程实践。
  3. 国产开源生态出海变量：Kimi K3 洽谈进入美国三大云平台（08-26 报道）；关注谈判结果、安全审查走向，及 GLM-5.3/DeepSeek 权重的下载-微调-部署生态数据。
  4. 具身智能”清场期”：宇树上市后估值回撤与”订单虚高”复盘并行；重点盯 2026Q4 真实交付数、Optimus 周产爬坡（1000→2500 台）兑现度、智元赴港进展，以及 2028–2029 成本拐点（<20 万元）相关供应链信号。
  5. 金融 AI 合规窗口：金发〔2026〕8 号的”18 个月达标窗口”（约至 2027 年末）；关注各行把 AI 治理写入十五五规划的具体文本、外部算力/开源代码库筛查的落地案例，以及智能问数在”准确率 + 指标口径治理”上的技术路线收敛。
  6. 数据口径债：榜单不可回溯是本工作流最大短板；若长期运营，建议每期把三榜单原始抓取存为 JSON 存档，自建历史序列。

六、推荐

  • 信源优先级：官方公告/监管原文 > 财新、新华社、IT之家、证券时报等一手报道 > 垂直媒体转述 > 社区讨论（仅作”业内讨论”级引用）。
  • 工具推荐：LiveBench 必须走浏览器渲染；llm-stats / artificialanalysis 用 WebFetch 即可；36氪等反爬站点按”标题级信息”降级处理并注明。
  • 阅读顺序建议（每日 3 分钟版）：页眉 pills → 国产专区判断行 → 性价比图 → 趋势三条。
  • 进阶：如转为每日定时任务，建议同时输出”与上一期的 diff 摘要”（哪些模型排名变化、哪些事件是新增），避免全量重读。

本 README 与工作流本身同步演进；结构或口径变更请先审阅再执行。数据随榜单实时变动，请以官方/原站为准。
