方法论：营销归因

1.什么是营销归因

1.1 什么是营销归因

移动归因的作用是帮助营销人员了解移动应用中用户行为或转化的来源。通过移动归因，营销人员可以确定哪些渠道、广告或活动吸引了用户并促使其进行转化，例如下载应用、注册账号、进行购买等。这样的信息对于优化营销策略、提高投资回报率以及改进用户体验非常重要。通过了解最有效的用户获取渠道和最具影响力的营销活动，企业可以更有效地分配营销预算和资源，并制定更具针对性和效果的营销策略。

1.2营销归因对应用营销的重要意义

  1. 了解营销效果： 归因可以帮助营销团队了解不同营销渠道和活动对用户行为的影响，包括应用下载、注册、购买等转化行为。通过准确归因，营销团队可以评估各种营销活动的效果，优化资源投放和调整策略，提高营销的效率和回报率。
  2. 优化用户体验： 通过归因，营销团队可以了解用户是如何发现和使用应用的，从而更好地理解用户的需求和行为路径。基于这些数据，可以优化应用的用户体验，提升用户满意度和忠诚度，减少用户流失率，实现用户增长和留存。
  3. 精准投放广告： 归因可以帮助营销团队识别和了解目标用户的特征和行为，包括其兴趣、偏好、购买意愿等。基于这些信息，可以实现精准定位和个性化投放广告，提高广告的点击率和转化率，降低广告成本，实现更好的营销效果。
  4. 实现ROI追踪： 归因可以帮助营销团队跟踪和分析不同营销活动的投入和产出，从而实现ROI（投资回报率）的追踪和评估。通过比较不同渠道和活动的投资和收益，可以确定最具效益的营销策略和渠道，优化预算分配，最大化ROI。

2.移动归因工作原理

2.1 归因服务原理

1.MMP SDK的集成

在移动归因（MMP，Mobile Measurement Partner）系统中，Adjust通过在广告主的app中植入SDK来实现精准的用户行为跟踪和广告归因，从而帮助广告主优化广告投放和提升营销效果。以下是植入的MMP SDK的目的：

  • 数据收集与追踪： Adjust SDK 被嵌入到应用后，当用户首次打开应用或进行某些操作时，SDK 会自动收集设备信息（如设备ID、广告ID、操作系统类型等）。这些信息被上传到 Adjust 的服务器以供分析和归因。
  • 归因匹配： Adjust SDK 通过将用户的安装数据与之前的广告点击或展示数据进行匹配，确定用户是通过哪个广告或渠道进行转化的。这种匹配可以通过多种方式进行，包括：
    • 广告ID匹配：如果用户在点击广告时留下了广告ID（如 GAID 或 IDFA），SDK 会将用户的安装与广告ID匹配，从而确定归因。
    • 指纹匹配：如果没有广告ID，Adjust SDK 会基于设备信息（如IP地址、设备型号等）生成“指纹”来匹配用户。
    • 深度链接归因：如果使用了深度链接或延迟深度链接，Adjust SDK 可以跟踪用户通过这些链接进行的转化行为。
  • 数据安全与隐私保护： Adjust SDK 遵循各大隐私法规（如 GDPR 和 CCPA），用户的隐私数据经过加密处理，确保数据的安全传输和存储。此外，Adjust SDK 提供数据匿名化功能，以符合严格的隐私要求。

2.MMP归因依赖的核心字段

  • **设备 ID：**指用来识别世界上每部智能手机 或平板电脑的一串数字和字母，只有 授权用户的设备 ID 才能被读取。
  • **IP 地址：**设备用于互联网通讯的确 切地址。
  • **用户代理：**标识用户浏览器和操作系统的一行文本
  • **时间戳：**用户点击广告链接的时间。
  • **首次安装：**指用户首次打开应用。

2.2 移动归因流程

1.MMP归因流程

  • 非SAN归因：绝大多数广告平台使用归因链接进行归因。MMP为各平台提供现成的归因链接，可以直接复制取用。按照广告主的归因要求选择单平台链接或者deeplink。

  • SAN归因：Meta ads、Apple Search Ads和Google Ads等SAN不依赖外部归因链接进行归因，而是接收MMP的查询，而是等待归因合作伙伴向其发送通过软件开发工具包 (简称 SDK，已安装在客户应用中) 收集的广告 ID。然后，SAN 会比对自己的记录，确认是否有匹配对应广告 ID 的交互，最后MMP会进行检查确认该转化是否是转化前的最后触点

2.内源归因流程

  • 在用户增长的场景下，除了依赖MMP的归因；考虑全局营销活动的时候还需要考虑广告主能自主控制的渠道；例如推荐，email，push，sms等。这些渠道不需要通过三方MMP进行数据抓取，可以通过自建link或者用户进端行为进行数据追踪及分析。

3.营销归因的基本概念

3.1 用户互动类型

  • 在广告归因中，用户交互行为指的是用户与广告内容之间的各种互动方式。这些行为可以直接影响广告归因模型如何分配转化功劳给不同的营销触点。一般来说点击比展示的归因优先级高，点击直接表明用户兴趣，易于追踪。展示间接影响用户行为，辅助了解品牌认知
    • 展示（View/Impression）： 广告在用户设备上被加载并显示，无论用户是否与广告进行了进一步的互动
    • 点击（Click）： 用户通过点击广告来访问广告主的网站或落地页。

3.2 归因时间窗口

  • 归因窗口期（Attribution Window）是营销归因中的一个概念，指的是从用户与广告互动（如点击或观看）到发生转化（如购买或注册）之间的时间跨度。在这个时间范围内，特定的用户行为（如点击或展示）可以被归因为对最终转化有贡献。
  • 不同的广告平台和营销渠道可能有不同的归因窗口期设置，这些设置可以基于行业标准、用户行为分析或特定的业务需求。归因窗口期可以是以下几种类型：
    • 点击归因窗口（Click-Through Attribution Window）：从用户点击广告到转化的时间。业内默认的标准点击归因窗口是 7 天。
    • 展示归因窗口（View-Through Attribution Window）：从用户看到广告到转化的时间，即使他们没有点击广告。业内默认的展示归因窗口是24h，一般来说展示比点击对广告转化的影响时间更短，因此窗口期短与点击窗口期。

4.营销归因的基本概念

在常见mmp归因优先级中。如果在一个新增激活前发生了多个有效互动，MMP会把该激活优先归因到点击，其次是展示；并会优先使用确定性归因，其次是概率匹配。

4.1 精确归因

  • 通过设备匹配完成。从记录的交互和安装中收集唯一的设备标识符，如果两个 ID 匹配，就可以将交互归因于安装。基于点击的设备匹配准确率达 100%，是最为可靠的归因方法。
    • Android：的唯一标识符是 Google 广告 ID (GAID)；安卓用户也可以选择退出广告个性化，拒绝与广告主分享 GAID
    • IOS：广告主标识符 (IDFA)；有在用户授予数据跟踪许可的前提下，IDFA 才能被读取
  • 除了 GAID 匹配外，安卓应用开发者还可以利用另一种方法开展精确归因:Google Play Referrer。借助 Google Play Install Referrer，开发者可以将安卓设备上的应用下载归因至 Google Play 商店应用页面上的点击。
广告 ID 明确用于广告目的。设备用户可选择重置 ID，也可拒绝共享 ID（例如限制广告跟踪设置）。
+ iOS 示例：IDFA
+ 安卓示例：GAID (安卓)
设备 ID 永久与设备关联，用户不可对其进行重置，也无拒绝共享该 ID 的权利。默认情况下，MMP 不会记录设备 ID，也不会存储原始设备 ID，我们仅将其用于归因。
+ iOS示例 ： IDFV (iOS)
+ 不支持Google Play服务的安卓设备:：OAID、Android ID、IMEI、Fire ID
Adjust reftag Adjust reftag 是 Adjust 为 iOS 和安卓端发生的每次点击或展示而创建的唯一 ID。但 Adjust 仅会使用安卓 reftag 进行归因匹配。 使用 referrer 匹配的点击是 Adjust 使用的术语，指使用安卓 reftag 的、基于点击的归因匹配。欢迎在这里

4.2 概率归因

  • 在移动归因平台（Mobile Measurement Platforms, MMPs）中，概率匹配模型（Probabilistic Matching Model）是一种常见的归因方法。该模型不依赖于用户的唯一标识符（如IDFA、GAID），而是基于一系列设备和上下文特征来匹配用户于广告的交互行为和端内应用行为。但是概率归因模型对于广告主来说是一种黑盒模型，具有不确定性。
    • 无标识符依赖：不依赖于IDFA、GAID等唯一标识符，可以在隐私保护政策严格的环境下继续进行有效归因。
    • 灵活性和适应性：能够适应多种设备和环境，适用于无法获取唯一标识符或跨设备的场景。
    • 一定的误差：由于是基于概率和特征相似度进行匹配，存在一定的归因误差，可能会出现误归因或漏归因的情况。
  • 对于内源的营销渠道，广告主本身就有用户的信息（uid等），因此不存在因隐私导致营销活动和用户端内行为无法关联的行为，因此概率归因常用于广告营销场景。

4.3 最后点击模型（Last Click Model）

最后点击模型是一种归因模型，根据转化行为发生时的最后一次广告点击，将所有的销售额归因给该点击。它基于”最后一次点击”的假设，即最后一个广告触点对于转化的产生起到了决定性的作用。

  1. 特点：
    • 简单易用：最后点击模型具有简单的实施和计算过程，只需追踪并记录最后一次广告点击即可进行归因分析。
    • 直接导致转化：该模型适用于直接导致转化的情况，将所有的销售归因于最后一个广告点击，特别适用于购买决策较为简单和快速的场景。
    • 忽略其他触点：最后点击模型忽略了其他广告对转化的影响，仅关注最后一次点击的触点。它假设前面的广告触点对转化的影响相对较小或可以被最后一次点击所代表。
  2. 使用场景和业务：
    • 电子商务：最后点击模型常被电子商务行业采用，特别是在购买决策较为简单且交易发生在在线平台的情况下。这是因为在这些场景中，用户倾向于直接点击广告并立即进行购买。
    • 即时交易：当销售过程可以追踪到明确的转化点，且转化过程非常快速时，最后点击模型能够提供简单而有效的归因分析。例如，订阅服务、软件应用程序等具有即时转化效果的业务。
    • 直接反应广告：最后点击模型适用于那些以触发直接反应为目标的广告活动，例如优惠券、限时折扣等。在这些情况下，用户往往直接点击广告并立即购买，最后点击模型能够准确反映广告触点对转化的贡献。

4.4 第一点击模型（First Click Model）

第一点击模型是根据转化行为发生时的第一个广告点击，将所有的销售额归因给该点击。它基于”第一次点击”的假设，即第一个广告触点对于转化的产生起到了决定性的作用。

  1. 特点：
    • 引导潜在客户：第一点击模型适用于关注引导潜在客户进入转化漏斗的情况。它强调广告的品牌影响力和意识提升，将销售归因于第一个接触点。
    • 品牌推广：该模型适用于品牌推广、新品发布等需要引导潜在客户接触品牌的业务。通过将销售归因于第一次点击，可以评估广告在建立品牌认知和培养兴趣方面的效果。
    • 着重引入阶段：第一点击模型适用于那些重视引入阶段的广告活动。在购买决策过程中，用户往往通过第一次接触广告来了解产品或服务，因此这个模型能够准确反映广告触点对引入阶段的影响。
  2. 使用场景和业务：
    • 品牌建设：品牌建设是一个长期过程，第一点击模型适用于需要评估品牌广告对引入新潜在客户的效果的场景。通过归因于第一个广告触点，可以了解品牌广告在潜在客户意识提升和培养兴趣方面的贡献。
    • 教育行业：在教育行业，学校和大学通常使用广告来吸引潜在学生。第一点击模型适用于这种情况下，可以衡量学校广告在吸引学生进入招生流程时的影响力。
    • 旅游业：旅游业通常通过广告来引导潜在游客了解旅游目的地或旅行产品。第一点击模型适用于评估旅游广告在吸引游客进入旅行规划阶段时的效果。

5.营销归因在业务中的应用

4.1 营销归因的关键节点

  • 大部分实际业务中除了各个业务线完单定义有较大的差异，其他整体用户流基本一致。因此从用户旅程的角度来看，在业务完成营销归因的关键节点如下：
    • 下载：通过各种营销方式在应用商店下载app
    • 注册：通过端外H5或者app进行注册
    • 完单：除了有web端完单页面，完单已经完全是端内行为，最终都是希望用户通过didi的各种app完单
      • 根据不同的角色，不分用户完单前需要进行进行身份核验，核验通过才能进行完单

4.2 归因在业务中的应用

归因在业务中通过区分新增用户归因和召回用户归因，有效映射用户旅程的关键触点。新增用户归因侧重于识别哪些渠道首次吸引用户，如应用下载和注册，而召回归因专注于通过个性化营销策略重新激活非活跃用户。两者均需精确数据追踪和归因模型分析，以优化营销预算，提升用户获取和留存效率。公司业务线众多，单个业务线的归因规则详见新增/召回归因文档。

  • 新增归因：在新增归因中重点关注用户下载，注册，首单的相关营销渠道归因
  • 召回归因：对于较为成熟的app，召回归因是精细化运营中必不可少的数据抓手。重点关注用户召回后的首次拉起，召回首单的营销渠道归因
