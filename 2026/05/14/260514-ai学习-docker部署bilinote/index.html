安装Docker

一步到位去官网安装https://www.docker.com/products/docker-desktop/

Docker报错 Virtualization support not detected

Docker 显示该错误是因为系统底层虚拟化组件未激活。

按照以下顺序排查：

确认硬件与系统环境

1.开启 CPU 虚拟化：按 Ctrl + Shift + Esc 打开任务管理器，切换至性能 > CPU，查看右下角是否显示虚拟化：已启用。若显示“已禁用”，需重启电脑进入 BIOS 开启 Intel VT-x 或 AMD-V。

2.开启 Windows 功能：按下 Win + R 键，输入 optionalfeatures 打开“启用或关闭Windows功能”，勾选以下选项：

虚拟机平台

适用于Linux的Windows子系统

(WSL)Hyper-V (若有，可勾选)

3.点击确定后，必须重启电脑。

强制开启虚拟化引导

即使 BIOS 和系统功能都开启了，Windows 的 Hypervisor 有时仍不会自动加载。

1.在任务栏搜索框中输入 PowerShell，右键选择以管理员身份运行。

2.输入以下命令并按回车：bcdedit /set hypervisorlaunchtype auto（提示“操作成功完成”即代表生效。）

3.执行 wsl –update 更新内核

4.随后再次重启电脑

下载BiliNote

一步到位去github下载https://github.com/JefferyHcool/BiliNote

开始部署（直接使用他人写好无踩坑bat，谢谢B站up主AI茶谈）

网页BiliNote设置

1、网页打开localhost后，点击全局设置，加入第三方中转站的模型供应商配置对应API_KEY 和 地址。

本人使用硅基流动![https://www.siliconflow.cn/]，欢迎大家使用我的邀请码：KaFfh47l；邀请链接：https://cloud.siliconflow.cn/i/KaFfh47l;

2、模型选择多模态模型，在中转转选择视觉类的差不多。

3、音频转写设置选择必剪（在线）。

4、下载配置输入对应视频平台的cookie。打开对应视频网站，F12刷新后复制cookie即可。

5、部署监控设置，需要保证后端FAST API、Whisper 模型和FFmpeg这三个已安装且正常运行即可。

BiliNote正常使用

1、记得点视频理解，模型选择和模型风格等其他按需选择。如还有其他问题参考b站BV1RmTq6nEhE。
