步骤 1：明确报告目的与汇报对象（定方向）

核心逻辑：受众不同，报告侧重点、呈现形式完全区分，先对齐目标再开展分析，避免无效堆砌数据。

对内同事（周 / 月度产品洞察）
侧重：功能细节、体验差异、迭代优化小点，轻量化数据对比。

面试官（求职面试场景）
侧重：完整产品体验拆解，覆盖硬件、软件、功能架构、定价、销量、真实用户差评 / 好评反馈。

老板 / 管理层（公司战略规划）
侧重：行业格局、竞品战略、市场机会，推荐使用「五看三定」战略分析模型，出自中信出版社《好战略，坏战略》。

核心前置问题：本次报告要解决什么业务问题？交付后要落地什么动作？

步骤 2：精准筛选对标竞品（选对分析对象）

打破 “只看同品类产品” 的传统思维，两大选品逻辑：

  1. 局部模块对标：无需对标完整产品，单一功能模块即可对标（例：产品游戏化激励模块对标各类游戏）
  2. 需求链路对标（跨品类竞品）：从用户原始需求出发寻找竞品（例：除甲醛仪器的竞品不只是净化器，茶叶也满足 “净化异味” 需求）
    避坑要点：不盲目罗列全行业产品，只选取和本次分析目标匹配的对标对象。

步骤 3：分层收集有效信息（一手信息优先）

核心准则：一手信息价值＞二手公开信息，区分 C 端、B 端产品不同信息获取渠道。

（1）C 端产品信息获取

  • 一手：亲自作为普通用户完整体验产品，记录操作、交互、痛点；电商评论、社区真实用户反馈
  • 短板：用户意见分散、主观性强，需批量汇总提炼共性问题

（2）B 端产品信息获取（公开数据少，多渠道深挖）

  1. 内部协同：对接销售、商业化团队，调取海关销售数据、平台销量榜单
  2. 伪装调研：伪装客户致电竞品销售，询问方案、报价、服务政策
  3. 上下游访谈：对接供应商、方案商，获取竞品成本、技术路线、客户合作情况
  4. 行业访谈：通过行业人脉、面试交流侧面获取竞品业务策略

（3）二手辅助信息源

行业咨询报告（艾瑞 / 亿欧）、海外科技媒体 The Verge、竞品官网、公开财报、新闻稿件。

步骤 4：搭建逻辑线组装完整报告（落地输出）

依托《金字塔原理》搭建总分总清晰逻辑，标准完整报告目录结构：

  1. 分析背景与本次分析目标
  2. 竞品定位、目标客群拆解
  3. 市场规模、销量、份额数据对比
  4. 产品功能、页面交互、视觉设计拆解
  5. 竞品推广渠道、营销投放策略分析
  6. 综合优劣势总结 + 市场机会点
  7. 落地行动项（报告核心价值）
    • 我方产品短期 / 长期优化目标
    • 推进所需跨部门资源、协作需求
    • 可量化落地执行方案

总结提炼

这套四步竞品分析法是从目标→对标→调研→落地的全链路闭环方法论，核心不是单纯 “拆解竞品”，而是以业务落地为最终导向：先根据受众确定分析深度，拓宽竞品筛选边界，优先采集一手真实数据，最后输出带可执行动作的结构化报告，区别于市面上只讲拆解、不提落地的浅层竞品分析教程。
