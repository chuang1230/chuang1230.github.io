量化风控全流程

1. 政策与定价 关注点

  1. 用户准入设计：排除高危用户后的目标客群
  2. 审核步骤设计：策略、模型及反欺诈的介入时机
  3. 授信金额的确认：不同审批流程中的授信金额幅度设计
  4. 不同风险等级的评级变换标准

2. 风控审批策略

2.1 审批策略架构搭建

步骤一：熟悉产品类型，了解进件流程

  • 了解进件流程：
    1. 收集进件流程中可获得的进件要素
    2. 寻找流程中的风险点，制定对应的风险排查方法
  • 熟悉产品类型：
    1. 明确审批对象
    2. 了解时长行业审批流程
    3. 评估在客群层面是否存在明显风险
    4. 明确目标客群的范围

步骤二：根据审批对象，制定主体策略模块

  • 常用的审批策略模块：个人信息验证、准入模块、欺诈判断、黑名单判断、信用风险评估、人工授信、交易风险
  • 策略模块原则：根据产品流程制定；每一个模块对应解决一个或多个风险点，找不到解决方案的风险点需要预留位置

步骤三：对应主体策略模块寻找风险解决方法

  1. 第三方数据源——数据源的选择标准：数据体量（查得率）、区分度（覆盖率）、收费标准、是否稳定、数据来源
  2. 增加进件要素获取
  3. 爬虫获取额外信息等

步骤四：根据确认的策略模块，设计审批流程

  1. 无费用的在前，有费用的在后
  2. 强风险在前，弱风险在后
  3. 尽可能留存信息

步骤五：确认审批流程落地方案

  1. 决策引擎
  2. 审批系统
  3. 征信平台

2.2 征信平台

作为第三方数据源回传数据统一存储的平台：

  • 记录每次查询的结果
  • 将原始数据处理为决策引擎可使用的字段
  • 可管理多个同质数据源

数据源介绍

类别 具体内容
基本验证 公安核查、人脸识别、活体检验、银行卡四要素验证（姓名、身份证、手机号、银行卡）、手机要素验证（是否实名一致）
黑名单（身份证、手机号） 法院执行人、欺诈名单、逾期、关注名单等
信用 多头借贷、信用分、互联网标签、银行卡信息

2.3 决策引擎

  1. 只是吃变量，且吐变量的系统
  2. 作用：将风控落地
  3. 与传统代码实现策略区别：风控业务可自行配置、更改；保密性更高；调整更快

2.4 策略调优

调优分类

  • A类调优：在拒绝客户中找好的客户通过（拒绝推断）
  • B类调优：在通过的客户中找到差的客户拒绝

调优原因

  • 资产质量朝着坏的方向发展
  • 逾期率过高通过率下降，预测坏账比超过预期

常用量化指标

指标 说明
逾期 账单逾期、订单逾期
逾期时段 M0/M1/M2/M3
资产质量 新增放款金额和预期金额
Vintage 观测不同类别资产在同阶段的逾期差异，观测逾期增长趋势（横轴：MOB）
首逾 FPD（FSTQPD） 首次逾期表现
PSI PSI = (A - B) × log(A / B)，衡量指标的波动程度

PSI 稳定性判断标准

  • PSI < 0.1：稳定性好 ✅
  • 0.1 ≤ PSI ≤ 0.25：关注 ⚠️
  • PSI > 0.25：异常 ❌

策略调优方法

  • 通过率下降分析：A节点拒绝率，B节点拒绝率（时间节点）
  • 针对A节点细化到规则层面深度分析：X准入、年龄、地区等
  • 做进件客户的年龄划分
  • 探索性规则分析

2.5 评分卡使用策略

  1. 什么时候需要：进件量大，规则无法满足更细的切分
  2. 使用场景：人工分流，客群豁免

2.6 额度调整策略

  1. 步骤：筛选可调额度用户，分为调额组和对照组，调整后分析两组的资产趋势，根据结果回调最初筛选可调额客户的规则
  2. 最初调额客户筛选方案：
    • 历史未逾期
    • 账龄达到6个月
    • 活跃月份占比超过80%
    • 额度使用率超过85%
    • 未办理过再分期业务
  3. 调额资产趋势分析：调额组逾期要高，将调额组多维度分析，寻找关键维度，回调筛选调额名单规则

3. 风控评分模型

3.1 确立评分目的

产品类型为小额无抵押个人，预测客户的借贷违约风险，对公司产品进行风险决策，减少损失。

3.2 模型设计

申请评分卡建立之前排除特殊进件（欺诈账户、政策拒绝账户、未激活账户等），以提高模型的预测效果（包括但不限于产品类型、地区、账龄）。

3.3 数据拉取及清洗

  • 数据来源：运营商数据、设备数据、短信数据、个人征信、个人基本信息等
  • 取数逻辑：根据观察期和表现期的定义从数据池中取数，并进行前期的数据清洗和稳定性验证
  • 数据清洗：用户唯一性检查、缺失值检查、异常值检查等
  • 稳定性验证：主要考察变量在时间序列上的稳定性，衡量指标有 PSI、均值/方差、IV 等

3.4 特征工程

  • 主要做特征（包括连续变量、离散变量、时间变量、文本变量等）的处理和筛选
  • 基于业务的深入理解做特征构造工作：特征交叉、特征转换、对特征进行四则运算等
  • 申请评分卡特殊要求：
    • 对特征进行离散化、归一化处理
    • 再进行降维处理，降维方法有 IV 筛选、显著性筛选、相关性筛选等

3.5 模型建立和评估

  • 选择合适的模型（申请评分卡用逻辑回归）
  • 模型评估：计算 AUC、KS
  • 对模型做交叉验证来评估泛化能力及模型的稳定性

3.6 模型上线部署

  • 在风控后台部署模型规则
  • 对于复杂的模型还要将模型文件进行转换，并封装成一个类，用 Java 等其他形式来调用

3.7 模型监控

  • 前期：主要监控模型整体及变量的稳定性，衡量标准主要是 PSI、混淆矩阵；每日观察规则的拒绝率与线下的差异
  • 后期：积累一定线上用户后可评估线上模型的 AUC、KS，与线下进行比较，衡量模型的线上实际效果

4. 反欺诈策略

4.1 客户引流项目风险评估

线下项目评估

  • 政策推广指引：根据产品定位设前端营销推广指引，包括渠道准入标准、客户进件条件、产品额度
  • 渠道准入：对前端上报渠道进行准入评估、渠道管控参数配置等
  • 渠道、营销员分级管理办法：对所属渠道、营销员的进件进行批核分析，客群质量评估、逾期数据统计等

线上项目评估

  • 渠道推广指引及准入
    • 客群准入：年龄、地域、手机、职业、收入、平台黑名单、平台逾期信息、平台自有数据等
    • 信息回传：设备信息、定位信息、平台信息
  • 系统对接及测试
    • UTA测试：流程验证、进件信息回传验证，新增回传信息
    • 生产验证：真实走一遍流程并后台验证相关信息
  • 上线监控及分析
    • 配套策略：上线该特定渠道的配套策略
    • 上线初期：进件控量，客群特征等基本属性分析，了解渠道客户特征
    • 进件监控：进件批核、拒绝原因分布及授信均额监控并优化
    • 逾期风险监控及策略调优：根据表现期后数据逾期情况，分析逾期客户特征，优化审批策略
    • 合作方新增回传信息分析应用

评估总结：线下注重渠道管理，线上注重反欺诈

4.2 反欺诈外部征信数据测试

产品类型

类型 说明
特殊名单（决策类）
黑名单 多头、逾期、被执行人、老赖、罪犯、一度二度关联
白名单 社保公积金、单位信息、地址信息、收入信息等
反欺诈评分（排序类） 反欺诈模型评分

基本流程

  1. 产品特征了解
  2. 数据提取
  3. 效果评估

测量方向的考量

  • 查得率、命中率、覆盖率等
  • 对客户评估的单调性、差异性、准确性
  • 对现有政策架构上的风险增益

4.3 提现策略流程搭建（以小额现金贷为例）

提现基本流程

  1. 内部基本规则：准入、黑名单、历史逾期异常行为、历史拒绝等
  2. 外部信息规则：外部多头、外部风险名单、外部信息联合拒绝等
  3. 进件和规则
  4. 贷中规则：贷中行为评分、有无还款行为等
  5. 通讯录反欺诈应用

4.4 反欺诈体系

欺诈类型

以盗刷、薅羊毛、骗贷、套现、刷单、刷好评为目的的（个人和团体欺诈）

表现形式

网络攻击：拖库、撞库、洗库、机器注册、暴力破解

术语 解释
拖库 黑产通过社工手段或者技术手段盗取目标网站客户资料数据
洗库 黑产通过将用户账户中的财产或虚拟财产通过各种黑产渠道进行变现
撞库 黑产将拿到的数据进行整理，利用这些数据对其他网站试探性登录，从而获得其他网站账号信息

其他形式：

  • 短信/电话劫持：伪基站、手机病毒、呼叫转移
  • 伪造资料：资料包装、证件伪造、伪冒身份

主要欺诈风险

中介欺诈

  • 一站式中介：伪造短信、买卖身份证、账号、修改定位、伪造通讯录、PS证件等
  • 零散中介：没有软件代扣、客户容易跑单

黑产欺诈

  • 猫池：养号神器
  • 群控系统：通过操作某个软件来控制一群用户批量注册、养号、接收短信验证码等
  • 伪基站
  • 其他技术：位置修改、号码修改、手机设备修改等

内外串通

主流反欺诈技术

技术层级 具体手段
数据采集 设备指纹、爬虫技术、生物识别、地理位置识别、活体检测、生物探针技术（采集用户在使用设备的按压力度、设备仰角等习惯，为其建立专属的行为模型，发现异常时及时阻断）
数据分析 运用数据分析工具从数据中发现知识：关系图谱（主要识别团伙欺诈）、机器学习技术（有监督、无监督和半监督）
决策引擎 反欺诈的大脑，可将信誉库专家规则和模型有效整合，提供一个操作方便、高效的人机交互界面，降低反欺诈的运营成本和响应时间

欺诈场景：盗用账户、网购运费险、网络欺诈

现金贷欺诈体系

阶段 内容
产品设计 产品或项目分析评估、制定反欺诈管理方案、反欺诈需求开发与落地
营销获客 渠道管理、投放策略管理、营销人员合规管理
贷前审批 进件管理、授信流程、提现流程、人工策略、反欺诈策略制定、贷前监控
贷后管理 贷中监控、案件调查

5. 贷后策略量化分析

5.1 催收策略制定方法

专业术语

术语 含义
DPD 合同最早一笔分期逾期到现在的时间间隔（Days Past Due）
RPC 有效联系人
PTP Promise to Pay（承诺还款）
Outbound/Inbound 电话呼出 / 呼入

催收手段

自动代扣、短信提醒、智能语音、上门催收、法务催收、委外催收、催收机器人

催收策略分流与量化

短信提醒 → 语音提醒 → M1电话催收组 → M2电话催收组 → M3电话催收组 → 上门催收 → 法务催收

5.2 催收常用量化指标

指标 说明
贷后回收率 整体回收表现
迁移率 M0→M1：本月末M1待收余额 / 上月末M0待收余额
催收绩效 1 - 迁移率
催收效果分析 人力不足？新老员工技能差异大？

上线策略调优逻辑

  • 短信发送时间优化
  • 外呼策略调整（比如每个合同固定一个催收员到当月最后一天，电话3天覆盖一遍，全天跟进PTP且不超过1.5小时）

5.3 催收评分卡

  • 业务现状：目前合规下，单靠逾期天数区分客户，精细化程度不高，无法区分高风险客户和低风险客户
  • 入模变量：近31天通话次数、客户所有未结清合同逾期天数大于等于3的次数、历史未接通次数等

6. 风险监控报表体系

审批监控指标

  • 拒绝原因分布
  • 审批量
  • 通过率
  • 放款量

监控意义

指标异常 应对动作
进件量浮动较大时 与前端销售同事沟通，寻找原因
通过率较大时 与政策同事沟通，寻找原因
核准金额与放款金额差异较大时 需了解是客户主动放弃、系统放款异常还是其他原因

Vintage 分析

以账龄为轴，观察贷后每个月的后续质量情况，可观测一个多期产品的风险全貌。

公式 用途

PSI < 0.1 稳定性好
0.1 ≤ PSI ≤ 0.25 需要关注
PSI > 0.25 异常，需紧急处理
迁移率 M0→M1 本月末M1待收余额 / 上月末M0待收余额
